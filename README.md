# joaosr.github.io/joaosr

Personal portfolio site — built with React, Vite, and Tailwind CSS.

Live at: https://joaosr.github.io/joaosr/

## Stack

- [React 19](https://react.dev/)
- [Vite 6](https://vite.dev/)
- [Tailwind CSS v4](https://tailwindcss.com/)
- Deployed via GitHub Actions → GitHub Pages

## Development

```bash
nvm use
npm install
npm run dev
```

## Deploy

Pushing to `main` triggers the GitHub Actions workflow which builds and deploys to GitHub Pages automatically.

To deploy manually:

```bash
npm run build
```
